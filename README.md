# Mapolis (pre-beta5)

## Branch & Deployment Status
- **Active Branch**: `pre-beta5`
- **Consumer Game**: `play/` (published to `play.mapolis.app`)
- **Admin/Educator Portal**: `play/admin/` (published to `mapolis-admin.netlify.app`)
